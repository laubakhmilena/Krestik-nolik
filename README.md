# Krestik-nolik

Krestik-nolik — браузерная игра «Крестики-нолики», сделанная на HTML, CSS и JavaScript. Проект подходит для тренировки логики, работы с DOM и простого игрового интерфейса.

## Возможности

- игра на одном устройстве с другом;
- режим игры с ботом;
- классический игровой экран;
- стилизация через CSS;
- отдельный архив `Krestik-nolik.zip` с версией проекта.

## Файлы

```text
index.html          разметка игры
style.css           внешний вид
script.js           логика ходов и проверки победы
Krestik-nolik.zip   архив проекта
```

## Запуск

Откройте `index.html` в браузере или запустите проект через локальный сервер.
