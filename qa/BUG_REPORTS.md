# Баг-репорты и кандидаты на дефекты

Проблемы выявлены статическим анализом публичного кода. `Needs validation` означает необходимость динамического воспроизведения.

---

## BUG-001 — На мобильном запрещено масштабирование страницы

**Статус:** Fixed
**Severity:** Major  
**Priority:** High  
**Компонент:** Accessibility / Mobile  
**Источник:** viewport содержит `user-scalable=no`.

**Шаги:**

1. Открыть игру на мобильном устройстве.
2. Попытаться увеличить интерфейс pinch-to-zoom.

**Фактический результат:** масштабирование запрещено настройкой viewport.  
**Ожидаемый результат:** пользователь может увеличить содержимое.  
**Влияние:** пользователям со сниженным зрением сложнее читать и взаимодействовать.  
**Исправление:** удалён `user-scalable=no`; ограничение масштабирования больше не задаётся в viewport.
**Проверка:** статическая проверка `index.html`; динамическая проверка pinch-to-zoom на физическом устройстве не выполнялась.

## BUG-002 — Абсолютный `/sdk.js` может возвращать 404 вне платформы

**Статус:** Needs validation  
**Severity:** Minor  
**Priority:** Medium  
**Компонент:** Integration / Console  
**Окружение:** localhost, GitHub Pages, статический хостинг.

**Шаги:**

1. Запустить через локальный HTTP-сервер.
2. Открыть Network.
3. Перезагрузить.
4. Проверить `/sdk.js`.

**Фактический результат:** запрос может завершиться 404.  
**Ожидаемый результат:** standalone-запуск не выполняет заведомо неуспешный запрос.  
**Влияние:** шум в Console/Network и риск различий запуска.  
**Рекомендация:** подключать SDK условно или только в целевом окружении.

## BUG-003 — Игровой интерфейс блокируется в landscape

**Статус:** Needs validation / Product decision required  
**Severity:** Major  
**Priority:** Medium  
**Компонент:** Responsive UI / Accessibility

**Шаги:**

1. Открыть игру в portrait.
2. Сделать ходы.
3. Повернуть устройство в landscape.

**Фактический результат:** появляется блокирующее сообщение о portrait.  
**Ожидаемый результат:** если portrait-only не является требованием, игра доступна в обеих ориентациях.  
**Влияние:** пользователь не может продолжить игру.  
**Рекомендация:** добавить landscape-layout или формально зафиксировать ограничение.

## BUG-004 — Семантика поля не полностью соответствует ARIA Grid Pattern

**Статус:** Needs validation  
**Severity:** Minor  
**Priority:** Medium  
**Компонент:** Accessibility / Screen reader

**Шаги:**

1. Включить screen reader.
2. Открыть игровое поле.
3. Проверить структуру и навигацию по клеткам.

**Фактический результат:** контейнер имеет `role=grid`, но дочерняя структура не содержит полного набора `row/gridcell`.  
**Ожидаемый результат:** поле распознаётся как понятная сетка 3×3.  
**Влияние:** сложнее понять структуру.  
**Рекомендация:** реализовать полный ARIA Grid Pattern или использовать группу кнопок без `role=grid`.

## BUG-005 — Accessible name занятой клетки может не сообщать X/O

**Статус:** Needs validation  
**Severity:** Major  
**Priority:** Medium  
**Компонент:** Accessibility / Game board

**Шаги:**

1. Включить screen reader.
2. Сделать ход.
3. Вернуть focus на занятую клетку.
4. Прослушать объявление.

**Фактический результат:** может объявляться только «Клетка N» без состояния.  
**Ожидаемый результат:** «Клетка N, занята X/O».  
**Влияние:** незрячий пользователь не восстанавливает состояние поля.  
**Рекомендация:** обновлять `aria-label` или `aria-describedby` после каждого хода.
