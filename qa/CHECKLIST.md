# Чек-лист тестирования

Статусы: `Pass`, `Fail`, `Blocked`, `Not Run`.

## 1. Запуск и стартовый экран

- [ ] Страница открывается без пустого экрана.
- [ ] В консоли нет необработанных JavaScript-ошибок.
- [ ] Заголовок отображается полностью.
- [ ] Кнопка «Начать играть» доступна.
- [ ] Кнопка имеет видимый focus.
- [ ] Enter открывает меню.
- [ ] Быстрый двойной клик не дублирует экраны.
- [ ] После загрузки снимается boot-state.

## 2. Главное меню

- [ ] Отображается выбор режима.
- [ ] «Игра с другом» активна.
- [ ] «Игра с ботом» активна.
- [ ] «Назад» возвращает на Start.
- [ ] Экраны не дублируются.
- [ ] Tab-порядок логичен.
- [ ] Скрытые элементы не получают focus.

## 3. Игра с другом

- [ ] Открывается поле 3×3.
- [ ] В начале ход X.
- [ ] Свободная клетка принимает X.
- [ ] Следующий ход принимает O.
- [ ] Ходы чередуются.
- [ ] Занятую клетку нельзя перезаписать.
- [ ] Невалидный клик не меняет очередь.
- [ ] Победа X определяется по трём строкам.
- [ ] Победа O определяется по трём строкам.
- [ ] Победа определяется по трём столбцам.
- [ ] Победа определяется по двум диагоналям.
- [ ] После победы поле блокируется.
- [ ] Победная линия выделяется.
- [ ] Статус показывает победителя.
- [ ] Ничья определяется корректно.
- [ ] После ничьей поле блокируется.
- [ ] Счёт X растёт один раз.
- [ ] Счёт O растёт один раз.
- [ ] Счёт ничьих растёт один раз.
- [ ] «Играть снова» очищает поле.
- [ ] «Играть снова» сохраняет счёт.
- [ ] «Сбросить счёт» обнуляет значения.
- [ ] Выход из активной партии открывает modal.
- [ ] «Остаться» сохраняет игру.
- [ ] «Выйти» возвращает в меню.
- [ ] Восстановление партии соответствует требованиям.

## 4. Игра с ботом

- [ ] Открывается выбор сложности.
- [ ] Доступны Easy, Medium, Hard.
- [ ] Выбранная сложность отображается.
- [ ] Во время хода бота ввод заблокирован.
- [ ] Бот делает один ход.
- [ ] Бот выбирает только свободную клетку.
- [ ] Бот не ходит после окончания партии.
- [ ] Easy не зависает.
- [ ] Medium блокирует очевидную победу.
- [ ] Hard не проигрывает при оптимальной игре.
- [ ] Смена сложности работает.
- [ ] Счёт bot-mode отделён от friend-mode.
- [ ] Повторная партия корректно выбирает первого.
- [ ] «Бот думает» показывается только во время расчёта.
- [ ] Выход во время таймера не создаёт ход на скрытом экране.

## 5. Темы

- [ ] Меню тем открывается и закрывается.
- [ ] Клик вне меню закрывает его.
- [ ] Все темы выбираются.
- [ ] Активная тема имеет `aria-checked=true`.
- [ ] Символы соответствуют теме.
- [ ] Уже поставленные символы обновляются.
- [ ] Подписи остаются читаемыми.
- [ ] Тема сохраняется после reload.
- [ ] Некорректный storage не ломает приложение.
- [ ] Меню управляется клавиатурой.
- [ ] Escape закрывает меню.

## 6. Локализация

- [ ] Русский текст без битой кодировки.
- [ ] Английский применяется полностью.
- [ ] Title переводится.
- [ ] Динамические статусы переводятся.
- [ ] Accessible names переводятся.
- [ ] Нет смешения языков.
- [ ] Длинный английский текст не ломает layout.

## 7. UI и адаптивность

- [ ] 320×568: нет обрезания.
- [ ] 375×667: поле помещается.
- [ ] 390×844: touch-target достаточен.
- [ ] 768×1024: layout корректен.
- [ ] 1366×768: интерфейс центрирован.
- [ ] 1920×1080: нет чрезмерных пустот.
- [ ] Zoom 200% не скрывает функции.
- [ ] Нет горизонтального скролла.
- [ ] Modal виден на маленьком экране.
- [ ] Safe-area учитывается.
- [ ] Смена orientation не зависает.
- [ ] Возврат в portrait сохраняет состояние.

## 8. Accessibility

- [ ] Основные действия доступны без мыши.
- [ ] Фокус видим.
- [ ] Modal удерживает focus.
- [ ] После закрытия focus возвращается.
- [ ] Клетки имеют понятные имена.
- [ ] Занятая клетка сообщает символ.
- [ ] `aria-live` не дублирует сообщение.
- [ ] Контраст соответствует WCAG AA.
- [ ] Состояние не передаётся только цветом.
- [ ] Масштабирование разрешено.
- [ ] Landscape не блокируется без требования.
- [ ] Grid корректно читается screen reader.

## 9. Совместимость и устойчивость

- [ ] Chrome.
- [ ] Edge.
- [ ] Firefox.
- [ ] Safari.
- [ ] Android Chrome.
- [ ] iOS Safari.
- [ ] Недоступный SDK не ломает игру.
- [ ] Ошибка `localStorage` обрабатывается.
- [ ] Многократные клики не создают два хода.
- [ ] Возврат на вкладку не ломает бота.
- [ ] Reload в середине игры имеет ожидаемое поведение.
- [ ] После нескольких партий нет новых ошибок в Console.
