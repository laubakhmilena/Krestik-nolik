# Тест-кейсы

## TC-001 — Переход со стартового экрана в меню

**Приоритет:** High  
**Предусловие:** приложение открыто, storage очищен.

**Шаги:** открыть приложение → нажать «Начать играть».

**Ожидаемый результат:** Start скрыт; отображается «Выберите режим игры»; обе карточки активны; ошибок Console нет.
