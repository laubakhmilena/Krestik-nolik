# Отчёт о тестировании

## Статус

**Дата аудита:** 30 июля 2026 года
**Динамический прогон:** выполнен в Chromium desktop и mobile-профилях Playwright
**Реальный Yandex Games SDK:** не проверялся
**Физические устройства и другие браузеры:** не проверялись

## Выполнено

- восстановлены `package.json`, Playwright-конфигурация и GitHub Actions;
- выполнены структурная и синтаксическая проверки;
- выполнена production-проверка статического приложения;
- запущены 8 Playwright smoke-сценариев в двух конфигурациях viewport;
- проверены запуск, навигация, friend mode, победа, счёт, рестарт, тема, повреждённое сохранение, модальное окно и выбор сложности;
- проверен fallback приложения при отсутствии SDK через локальный запуск.

## Автоматизированное покрытие

| Область | Покрытие |
|---|---|
| Start и Menu | Smoke |
| Friend mode | Ходы, занятая клетка, победа, счёт, рестарт |
| Сохранение | Повреждённое состояние и тема |
| Bot mode | Выбор сложности |
| Responsive | Desktop и mobile Chromium viewport |
| SDK | Локальный fallback; реальная платформа не проверялась |

## Дефекты

BUG-001 исправлен: снято ограничение `user-scalable=no`. BUG-002—BUG-005 остаются `Needs validation`, поскольку требуют ручной проверки в соответствующем окружении или screen reader.

## Ограничения

Playwright-тесты выполнялись в Chromium. Firefox, Safari, реальные Android/iOS-устройства, публикация и Yandex Games SDK в этом аудите не проверялись. Отдельных unit-тестов нет.
